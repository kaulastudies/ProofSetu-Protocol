# Contributing to ProofSetu Protocol

Thank you for your interest in contributing to ProofSetu Protocol.

ProofSetu Protocol is an open-source verifiable workflow proof layer for documents, milestones, invoices, grant deliverables, and AI-assisted decisions, built with future Stellar/Soroban integration in mind.

## Project Goals

The project aims to create a lightweight and privacy-conscious proof infrastructure where users can create and verify tamper-evident proof records without exposing private documents.

## Current Development Stage

The project is currently in the early MVP planning and setup stage.

Current focus:

* Documentation
* Example proof records
* Web MVP planning
* Proof creation and verification flow
* Future Stellar/Soroban testnet integration

## Ways to Contribute

You can contribute by helping with:

* Documentation improvements
* Use-case examples
* UI/UX suggestions
* Web MVP development
* Hash generation logic
* Stellar/Soroban smart contract development
* Testing and feedback

## Development Principles

ProofSetu Protocol follows these principles:

* Open-source first
* Privacy-conscious design
* Simple user experience
* Verifiable proof without exposing sensitive data
* Real-world workflow usefulness
* Clear documentation

## Privacy Rule

Do not commit private documents, patient data, client files, financial records, or sensitive personal information to this repository.

Only sample or dummy data should be used in examples.
