# Roadmap

ProofSetu Protocol will be developed step by step, starting with a simple web MVP and later adding Stellar/Soroban integration.

---

## Phase 0 — Repository Setup

### Goal

Create a clean open-source repository with basic documentation and example proof records.

### Tasks

* Add README
* Add MIT License
* Add grant proposal document
* Add milestones document
* Add architecture document
* Add use cases document
* Add roadmap document
* Add example proof JSON files

### Status

In progress.

---

## Phase 1 — Web MVP

### Goal

Build a simple working web demo for creating and verifying proof records.

### Planned Features

* Landing page
* Create Proof page
* Proof type selection
* Event details form
* Hash generation
* Local proof registry
* Public verification page
* Example proof records

### Outcome

Users should be able to create a proof record and verify it through a public proof page.

---

## Phase 2 — Stellar/Soroban Testnet Integration

### Goal

Anchor proof records on Stellar/Soroban testnet.

### Planned Features

* Soroban proof registry contract
* Stellar testnet deployment
* Wallet connection
* On-chain proof creation
* On-chain proof retrieval
* On-chain proof verification
* Contract documentation

### Outcome

Users should be able to create and verify proof records using Stellar/Soroban testnet.

---

## Phase 3 — Public Demo and Grant Readiness

### Goal

Prepare ProofSetu Protocol for public review, community feedback, and grant submission.

### Planned Features

* Public demo deployment
* Screenshots
* Video walkthrough
* Improved documentation
* Grant proposal refinement
* Community feedback collection
* Demo use-case pages

### Outcome

The project should be ready for Stellar Community Fund-style review and public evaluation.

---

## Phase 4 — Mainnet-Ready Version

### Goal

Prepare the protocol for production-grade usage.

### Planned Features

* Mainnet deployment plan
* Security review checklist
* Improved UI/UX
* API access
* Better proof verification experience
* Real-world pilot use cases
* Maintenance plan

### Outcome

ProofSetu Protocol should be ready for real-world workflow proof use cases and future ecosystem growth.

---

## Long-Term Vision

ProofSetu Protocol aims to become a lightweight open-source trust layer for:

* Workflow proof
* Document proof
* Invoice proof
* Milestone proof
* Grant deliverable proof
* Donation usage proof
* AI-assisted decision proof
* Cross-border service proof

The long-term goal is to connect verifiable workflow events with Stellar-based payments, stablecoins, remittance, escrow, and settlement flows.
