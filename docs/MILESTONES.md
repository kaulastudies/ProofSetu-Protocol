# Milestones

ProofSetu Protocol will be developed in three simple milestones.

The goal is to start with a working web MVP, then add Stellar/Soroban testnet integration, and finally prepare a mainnet-ready version.

## Milestone 1 — Web MVP Demo

### Goal

Build a simple working demo where users can create and verify workflow proof records without blockchain complexity.

### Deliverables

* Landing page
* Proof creation form
* Hash generation
* Local proof registry
* Public proof verification page
* Example proof records
* Basic documentation

### Completion Criteria

* A user can create a proof record.
* A user can generate a proof hash.
* A user can view a public verification page.
* Example proof records are available in the repository.
* The demo can be shown publicly.

---

## Milestone 2 — Stellar Testnet Integration

### Goal

Anchor proof records on Stellar/Soroban testnet using a simple proof registry smart contract.

### Deliverables

* Soroban proof registry contract
* Stellar testnet deployment
* Wallet connection
* On-chain proof creation
* On-chain proof verification
* Contract usage documentation

### Completion Criteria

* Proof records can be written to Stellar testnet.
* Proof records can be retrieved from the contract.
* Proof hashes can be verified.
* Contract address and usage guide are published.

---

## Milestone 3 — Mainnet-Ready Launch

### Goal

Prepare ProofSetu Protocol for public launch, community feedback, and grant evaluation.

### Deliverables

* Improved UI/UX
* Mainnet-ready contract plan
* Security review checklist
* Public demo deployment
* Video walkthrough
* User feedback report
* Deployment guide

### Completion Criteria

* Product is ready for public demonstration.
* Documentation is complete.
* Demo use cases are available.
* Mainnet launch plan is published.
