# ProofSetu Protocol Grant Proposal

## Project Summary

ProofSetu Protocol is an open-source workflow proof layer built on Stellar/Soroban.

It allows users to create tamper-evident proof records for documents, milestones, invoices, grant deliverables, and AI-assisted workflow decisions.

Private documents stay off-chain. Only hashes, timestamps, proof metadata, and verification references are recorded for public verification.

## Problem

Many real-world workflows depend on trust, but the proof is scattered across WhatsApp messages, emails, PDFs, screenshots, spreadsheets, and internal systems.

This creates problems such as:

* Delayed approvals
* Disputes between clients and service providers
* Weak audit trails
* Poor transparency in donation or grant usage
* Lack of accountability for AI-assisted decisions
* Difficulty proving whether an important workflow event happened at a specific time

## Proposed Solution

ProofSetu Protocol creates a simple proof registry for real-world workflow events.

Users can create a proof record, generate a hash, and later verify that the same event or document existed at a specific time.

In later milestones, ProofSetu will anchor proof records on Stellar/Soroban using a simple smart contract.

## Stellar/Soroban Integration

ProofSetu will use Stellar/Soroban to store and verify proof records.

The initial Soroban proof registry will support:

* Creating proof records
* Retrieving proof records
* Verifying proof hashes
* Connecting proof records to wallet addresses
* Supporting public verification pages

ProofSetu can help bring verifiable trust infrastructure to real-world service and financial workflows.

It can later connect with Stellar-based payments, stablecoin settlement, invoice approval, milestone releases, and cross-border service delivery.
